========================================================================
 약, 알고 사용하기 - 국민 의약품 안심 안내 포털 (README.txt)
========================================================================

1. 웹사이트 실행 방법
------------------------------------------------------------------------
(1) 전달받은 medicine-portal 압축 파일을 적절한 폴더에 해제합니다.
(2) 해제된 폴더 내의 `index.html` 파일을 마우스로 더블클릭합니다.
(3) 기본 웹브라우저에서 포털 웹사이트가 바로 실행되고 모든 검색 및 안내 기능이 작동합니다.

2. 서버 미사용 안내 (로컬 단독 실행)
------------------------------------------------------------------------
본 웹사이트는 Node.js, Express, Apache, Nginx 등의 웹 서버나 백엔드 로컬 개발 서버(Live Server 등)가 전혀 필요하지 않은 100% 클라이언트 전용 정적 포털 웹사이트입니다.

3. 권장 지원 브라우저
------------------------------------------------------------------------
- 최신 Microsoft Edge (권장)
- 최신 Google Chrome (권장)
- 최신 Mozilla Firefox, Apple Safari
※ HTML5 및 CSS3 표준을 준수하는 모든 현대적인 웹 브라우저를 지원합니다.

4. 파일 구조
------------------------------------------------------------------------
medicine-portal/
├─ index.html                  # 메인 구조, 검색/안내/모달 시맨틱 HTML5
├─ css/
│  └─ style.css                # 반응형 레이아웃, 고대비 웹 접근성 CSS3 스타일시트
├─ js/
│  ├─ data.js                  # 로컬 의약품 데이터베이스 (전역 변수 medicineData)
│  └─ app.js                   # 순수 Vanilla JS 검색, 필터, 페이지네이션, 모달 제어 logic
├─ assets/
│  ├─ icons/                   # (인라인 SVG 및 CSS 도형 대체 처리)
│  └─ images/
└─ README.txt                  # 본 설명서 파일

5. 의약품 데이터 수정 방법
------------------------------------------------------------------------
`js/data.js` 파일을 메모장, VS Code, Notepad++ 등의 텍스트 편집기로 엽니다.
`const medicineData = [ ... ];` 배열 내부의 객체 항목을 수정하거나 새로운 의약품 객체를 동일한 양식으로 추가한 뒤 저장하면 즉시 반영됩니다.

6. data.js의 데이터 항목 설명
------------------------------------------------------------------------
- id: 의약품 식별 번호 (예: "MED-2026-001")
- productName: 의약품 제품명
- ingredientName: 성분명 (예: "아세트아미노펜")
- ingredientAmount: 성분 및 함량 (예: "아세트아미노펜 500mg")
- company: 제조/수입 업체명
- category: 약효 분류 (예: "해열·진통·소염제")
- prescriptionType: "일반의약품" 또는 "전문의약품"
- dosageForm: 제형 (예: "정제 (알약)", "현탁액")
- efficacy: 효능·효과 설명 문구
- dosage: 용법·용량 설명 문구
- precautions: 복용 시 주의사항 객체
  - beforeUse: 복용 전 확인사항 배열
  - duringUse: 복용 중 주의사항 배열
  - contraindications: 금기사항 배열
  - pregnancyAndLactation: 임신·수유 주의 배열
  - childrenAndElderly: 소아·고령자 주의 배열
  - driving: 운전/기계조작 주의 배열
- storage: 보관 방법 객체 (온도, 습도, 용기, 개봉 후)
- disposal: 폐기 방법 안내 문구
- adverseReactions: 이상반응 3단계 객체 (common, consultPromptly, emergency)
- interactions: 상호작용 4종 객체 (medicines, food, alcohol, supplementsAndHerbal)
- source: 공공자료 출처 객체 (제공기관, 데이터셋명, 원문명, 기준일, 갱신일)

7. 공공자료 기준일과 갱신 방법
------------------------------------------------------------------------
- 공공자료 기준일: 2026년 07월 01일
- 데이터 갱신 방법: 공공데이터포털(data.go.kr) 또는 의약품안전나라(nedrug.mfds.go.kr)에서 공개되는 의약품 개별 품목 허가 데이터를 내려받아 `data.js` 파일의 항목 형식에 맞게 정제하여 교체합니다.

8. 개발용 예시 데이터 교체 경고
------------------------------------------------------------------------
[경고] 본 포털에 기본 탑재된 데이터에는 데이터 구조 및 화면 동작 테스트를 위해 식약처 공개 양식을 참고하여 작성된 [개발용 예시 데이터]가 수록되어 있습니다.
실제 서비스 적용 전에는 반드시 공공기관이 공시한 공식 공공데이터로 교체하여야 하며, 본 화면의 정보를 실제 의학적 진단 및 치료 판단용으로 사용해서는 안 됩니다.

9. 외부 API 및 사용자 추적 기능 미사용 안내
------------------------------------------------------------------------
- 실시간 외부 API 호출이나 원격 데이터베이스 연결을 일절 하지 않습니다.
- 사용자의 검색어, 위치정보, IP 주소, 개인정보를 외부 서버로 전송하지 않습니다.
- 트래커, 분석 스크립트, 광고 스크립트 및 쿠키 기반 추적 기능을 전혀 포함하지 않습니다.

10. Local file:// 실행 환경 최적화
------------------------------------------------------------------------
본 웹사이트는 `file://` 로컬 프로토콜 실행 환경에서 브라우저의 CORS(Cross-Origin Resource Sharing) 정책으로 인해 외부 JSON 파일 `fetch()` 로딩이 차단되는 현상을 방지하고자, 데이터 구조를 `js/data.js` 파일 내 전역 JavaScript 객체로 정의하였습니다. 따라서 어떠한 브라우저 보안 제약 없이 `index.html` 더블클릭만으로 모든 기능이 안정적으로 실행됩니다.
